# 🌟 Soutien + – Site Vitrine

Bienvenue sur le site officiel de **Soutien +**, une entreprise de soutien scolaire individuel en **mathématiques, physique et informatique**, conçue **par des étudiants en classes préparatoires pour les collégiens et lycéens**.

---

## 🚀 Objectif du projet

Créer une plateforme simple et professionnelle permettant :
- de présenter l'entreprise Soutien +
- d'expliquer nos services (soutien en maths, physique et info)
- de permettre aux élèves ou parents de **s’inscrire facilement** via un formulaire

---

## 🛠️ Technologies utilisées

- **Frontend** : HTML5, CSS3, JavaScript (vanilla)
- **Backend** : Python 3 – Django Framework
- **Base de données** : SQLite (par défaut)
- **Emailing** : `django.core.mail` pour recevoir les inscriptions
